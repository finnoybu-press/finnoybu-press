**The book I wish existed when I started using AI to write code.**

Not a product manual. Not a prompt cookbook. Not a manifesto about how AI will replace developers (it won't) or a screed about how AI is just autocomplete (it isn't). A practical, comprehensive guide to building AI into your software development workflow, across every major tool, every phase of development, and every kind of project you're likely to meet.

**AI for Developers** covers GitHub Copilot, Claude Code, OpenAI Codex, Cursor, Google's Antigravity, Amazon's Kiro, and the general-purpose assistants. It teaches you how to use them together, when to reach for each one, when to hand a task to an agent, and, critically, when to close the AI tab and think for yourself.

This book assumes you can already code. It builds a systematic AI-augmented workflow on top of skills you already have.

## What's inside

**Getting started.** What AI means for development now, the late-2026 tool landscape, and an environment with an editor assistant, a coding agent, a chat assistant, and the instruction files (`AGENTS.md`, `CLAUDE.md`) that make them follow your conventions.

**Core workflows.** Writing, reviewing, debugging, refactoring, testing and documentation, with the patterns that work, the patterns that fail, and how to brief and check an agent at each step.

**Architecture and domains.** Architecture decisions with AI in the loop, frontend, backend, DevOps and infrastructure, with the guardrails that keep agents away from production.

**Codebase and infrastructure.** Large codebases and monorepos, Git workflows and agent pull requests, and API development, including exposing your API to agents through MCP.

**Specialized development.** Security (including the risks agents themselves create), databases, and mobile.

**Working with AI.** Pair programming versus delegating, and a field guide to what goes wrong, from hallucinated APIs to agents that quietly delete the failing test.

**AI products and teams.** Building AI features and agents into your own applications, and adopting AI across a team with honest measurement and a clear agent policy.

**Reference.** Tool comparison tables, 48 prompt patterns, configuration guides, a glossary, and curated further reading.

For the developer who has read an agent's summary that said "all tests pass" and wondered what it changed to get there, this book is for you.

**The 2027 Edition is revised throughout for late 2026: coding agents in every major tool, the reshuffled tool landscape (Codex, Antigravity, Kiro, Devin Desktop), current install steps and prices, balanced productivity research, and extensive new agent workflow and security material.**
